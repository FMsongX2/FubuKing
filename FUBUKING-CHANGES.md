# FubuKing changes to files without comment syntax

Apache-2.0 §4(b) asks every modified file to say that it changed. Source files carry the notice on their first lines. The upstream Atlas files below cannot hold a comment, so this list is their notice.

Every file listed here was modified by FubuKing from upstream Atlas (Apache-2.0). An entry ending in `/` covers every modified file under that directory.

- `src-tauri/tauri.conf.json`: product name, bundle identifier, window title, descriptions, bundled licence files.
- `src-tauri/tauri.linux.conf.json`: window title, package `provides` names.
- `src-tauri/tauri.windows.conf.json`: window title, publisher, homepage.
- `.gitignore`: tracks this file.
- `src-tauri/icons/`: every app icon, the DMG icon and background, and the icon sources, replaced with the FubuKing rice-grain artwork.
- `Cargo.lock`: regenerated by Cargo for the `fubuking` and `atlas-shared-memory` workspace crates.
